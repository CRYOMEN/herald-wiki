# AGENTS.md — Herald Lore Wiki

This repository is a lore / worldbuilding wiki for the game/story *Herald*, built from Markdown files. It holds the canonical world reference alongside space for drafting and creative work (see `Ideas/`). This file is always-on context for any coding agent (Codex, Claude, Cursor, Gemini, …) working here.

## Repository structure

Orientation for where things live:

| Folder | Contents |
|---|---|
| `Characters/` | Character sheets |
| `Locations/` | Settlements, cities, planets, geography |
| `Factions/` | Organizations and communities |
| `Technology/` | Human and alien technology |
| `Events/` | Narrative events |
| `Relationships/` | Relationship catalogs |
| `Game/` | Game-design documentation |
| `Records/` | Temporary inbox for raw notes |
| `Ideas/` | Temporary inbox for brainstorms and drafts |

Canon language: English. File naming: Short Title Case with spaces (e.g. `Alien Tech.md`).
