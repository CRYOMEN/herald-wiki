# Technology

This directory documents the technological aspects of the Herald universe. It includes details on:
- **Alien Biotechnology:** The "Living Suits" (symbiotic exoskeletons), genetic synthesis, and bio-organic systems.
- **Human Technology (2070):** Advanced silicon-based robotics, AI, and industrial hardware.

It serves as a reference for comparing the "wetware" of the Heralds with the "hardware" of humanity.
